# TF-58 coordination — real long fixture (`idsse_half`, DFL-MAT-J03WMX)

A reduced, committed slice of the **DFL-MAT-J03WMX** match, the one real, public tracking fixture long
enough for the §9.5 coordination liveness gate to exercise the spectral median frequency
(`coord_median_freq_cpm`) and the four coherence columns (`coord_coh_*`) on real data. Every committed
synthetic / provider tracking fixture is < 260 s — below both the spectral (≥ 2 periods of `band_low`) and
coherence (≥ 4 Welch segments) minima. Regenerated byte-for-byte by
[`generate_fixture.py`](generate_fixture.py) (ADR-056); the reproduction test is `e2e` because it needs the
data token.

## Reduction recipe (reproducible)

`generate_fixture.py` loads the full match through the repo's own `pining` loader
(`load_match(ref, events_only=False)` for provider `idsse`; token from `PINING_FOR_THE_DATA_TOKEN`), then:

1. keeps period 1 with `time_seconds < 1200`;
2. keeps every other frame (`frame_id` rank even) → 12.5 Hz, and sets `frame_rate = 12.5`;
3. keeps the `TRACKING_FRAMES_COLUMNS` columns, sorted by `(frame_id, player_id)` (stable, NA last);
4. keeps period-1 actions whose `time_seconds` lies inside the frame span;
5. writes both with pinned parquet settings (`engine="pyarrow", compression="zstd", index=False`);
6. the committed files were written with pandas `3.0.2` and pyarrow `25.0.1`. A parquet footer records both
   versions, so the bytes reproduce only under that writer: `test_idsse_half_repro.py` checks this line against
   both footers, and the e2e reproduction test refuses another interpreter.

## Preconditions (asserted in CI — `test_liveness.py::test_idsse_half_preconditions`)

- duration ≈ **1199.9 s** (≥ 1,100 s);
- `ball_state` carries **3** dead intervals > 25 s (max ≈ 51.3 s) (≥ 1);
- actions span the window with **1 goal** and **16** restart actions (≥ 1 goal, ≥ 5 restarts);
- both teams field **10 outfield players in 100 %** of samples (≥ 90 %).
