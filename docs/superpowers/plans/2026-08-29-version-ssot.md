# Version Single-Source-of-Truth (SSOT) Implementation Plan

> **For agentic workers:** This plan lands as **ONE coherent, fully-tested commit** on a **single feature branch** — **NO per-step commits, NO micro-commits, NO worktrees**. The terminal commit is **gated on Karsten's explicit approval** (show the diff, wait for an explicit "yes"); "tests pass" and "the plan says commit" are **not** approval. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Collapse the two hand-typed copies of the package version (`pyproject.toml [project] version` and `silly_kicks/__init__.py __version__`) into a single source, `silly_kicks/_version.py`, so a release bumps exactly one line.

**Architecture:** New `silly_kicks/_version.py` holds the one `__version__` literal. `pyproject.toml` declares `dynamic = ["version"]` and `[tool.hatch.version] path = "silly_kicks/_version.py"`, so hatchling derives the wheel/sdist metadata version from that module. `silly_kicks/__init__.py` re-exports it. Wheel metadata and the runtime `silly_kicks.__version__` therefore derive from one source and cannot drift. Mirrors `ruthless-efficiency` ADR-002 (decisions 5 & 6).

**Tech Stack:** Python (≥3.10), hatchling (build backend, already in use), `uv` (lockfile), pytest (guard test + regression net).

**Spec:** `HANDOFF-version-ssot.md` (repo root — the approved spec; go straight to plan + ADR, no separate spec).

- [ ] **Step 1: Write the failing test**

```python
"""Guard: the package version has ONE editable source — silly_kicks/_version.py.

Deleting the pyproject/__init__ duplication is what fixes drift (ADR-079); this test guards the
one thing deletion cannot — *reintroduction*. It fails the moment someone puts a static
`version = "..."` back into `[project]` (which would silently disagree with `_version.py`, since a
static-only pyproject still builds), or lets `__init__` hard-code a literal instead of re-exporting.

py3.10-safe: `tomllib` is 3.11+ and `tomli` is not a test dep, so the pyproject tables are read with
a scoped regex, mirroring tests/test_ci_publish_guard_wired.py.
"""

from __future__ import annotations

import pathlib
import re

import silly_kicks

_REPO = pathlib.Path(__file__).resolve().parent.parent
_PYPROJECT = _REPO / "pyproject.toml"
_VERSION_MODULE = _REPO / "silly_kicks" / "_version.py"


def _project_table() -> str:
    text = _PYPROJECT.read_text(encoding="utf-8")
    m = re.search(r"^\[project\]\s*$(.*?)(?=^\[)", text, re.MULTILINE | re.DOTALL)
    assert m is not None, "could not locate the [project] table in pyproject.toml"
    return m.group(1)


def test_project_declares_version_dynamic_and_carries_no_static_literal() -> None:
    table = _project_table()
    # No `version = "x.y.z"` static literal in [project].
    assert re.search(r"^\s*version\s*=", table, re.MULTILINE) is None, (
        "pyproject [project] carries a static `version` — reintroduces the second source that "
        "ADR-079 deleted. The version lives ONLY in silly_kicks/_version.py."
    )
    # `dynamic` lists "version".
    dyn = re.search(r"^\s*dynamic\s*=\s*\[(.*?)\]", table, re.MULTILINE | re.DOTALL)
    assert dyn is not None, "pyproject [project] must declare `dynamic = [...]`"
    assert "version" in re.findall(r"['\"]([^'\"]+)['\"]", dyn.group(1)), (
        "pyproject [project].dynamic must contain 'version' so hatchling derives it from _version.py"
    )


def test_hatch_version_source_points_at_the_version_module() -> None:
    text = _PYPROJECT.read_text(encoding="utf-8")
    tbl = re.search(r"^\[tool\.hatch\.version\]\s*$(.*?)(?=^\[|\Z)", text, re.MULTILINE | re.DOTALL)
    assert tbl is not None, "pyproject must declare [tool.hatch.version]"
    path = re.search(r"^\s*path\s*=\s*['\"]([^'\"]+)['\"]", tbl.group(1), re.MULTILINE)
    assert path is not None and path.group(1) == "silly_kicks/_version.py", (
        "[tool.hatch.version].path must be 'silly_kicks/_version.py' (the single source)"
    )


def test_version_module_literal_is_what_the_runtime_exposes() -> None:
    # The literal in _version.py IS silly_kicks.__version__ (guards __init__ hard-coding a divergent
    # value instead of re-exporting). Reads the module text; does not import install metadata.
    src = _VERSION_MODULE.read_text(encoding="utf-8")
    literal = re.search(r"^__version__\s*=\s*['\"]([^'\"]+)['\"]", src, re.MULTILINE)
    assert literal is not None, "silly_kicks/_version.py must define a `__version__ = \"...\"` literal"
    assert literal.group(1) == silly_kicks.__version__, (
        "silly_kicks.__version__ diverges from silly_kicks/_version.py — __init__ must re-export it, "
        "not hard-code its own literal"
    )
```

## Post-review hardening — VSSOT-IMPL-03 (in scope; directed by the independent `/review-impl`)

The `[train]` sklearn marker fix (Task 5) opened a footgun the review flagged: a py3.10 `[train]` install could fit and ship ghost weights under an unsupported sklearn, guarded only by a comment. Two small in-scope changes close it; the strategic "drop py3.10 (ADR-057)" question is deliberately NOT this PR's — left as Karsten's separate conscious decision (recorded in the review report).

- **Upper bound** — `[train]` `scikit-learn>=1.9` → `>=1.9,<2` (mirrors `xgboost>=2.0,<4.0`): a floor with no ceiling drifts to a future major that changes the trees. Re-locked; no-op resolution (1.9.0 still selected), `uv lock --locked` consistent.
- **Fail-loud fit-time guard** — `scripts/_train_guard.require_training_sklearn()` (raises outside `[1.9, 2)`), wired into the **ghost** trainer's `main()`. Ghost-scoped by design and by evidence: HistGradientBoosting is minor-version-sensitive (measured different sha256 at 1.7.2 vs 1.9.0), while the logistic bundles (gk_completion/retention/receiver) fit a convex, version-stable problem and their own load checks compare the MAJOR version only, so 1.7 vs 1.9 is a non-issue for them. Placed at the TRAINER, not `GhostGkModel.fit()` (the non-slow library unit tests fit toy models on the leg's own sklearn). The ghost smoke tests (`test_train_ghost_gk_cli.py`, all `@slow`) gain a module-level `skipif(not sklearn_supports_training())` so they **skip** (not fail) when the env is out of range — CI's 3.12 primary leg always has sklearn≥1.9, so coverage is unchanged there; a stale dev env (1.8.0) or a future 2.0 skips cleanly.
