# TF-52 Event-only Team-KPI Module — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `silly_kicks.team_metrics` — an event-only, per-`(game_id, team_id)` team-KPI module (Twelve glossary + event-based practitioner set) plus a public, reproducible reliability artifact.

**Architecture:** One `compute_team_kpis(actions, *, xg_column, params) -> (samples, TeamKpiReport)` orchestrator over pure-pandas family helpers, all resting on a single possession-foundation layer that reuses `spadl.add_possessions`. A frozen `TeamKpiParams` carries every threshold; a `TeamKpiReport` conserves the population. A scripts-side driver runs the reliability study on public StatsBomb-open + Wyscout data.

**Tech Stack:** Python, pandas, numpy; `silly_kicks.spadl` (converters, `add_possessions`, `spadlconfig`, reflection), `silly_kicks.id_compat` (dtype-safe ids). Driver: the shared `scripts/_driver.py` / `_provenance.py` / `_corpus.py` / `_input_contract.py` seams; `statsbombpy` (scripts-only) for SB-open loading.

**Spec:** `docs/superpowers/specs/2026-09-15-tf52-team-kpi-design.md` (round-2 APPROVED). The plan argues from the spec; executors read both.

## Global Constraints

Every task's requirements implicitly include this section. Values are copied verbatim from the spec.

- **Event-only, hexagonal.** `team_metrics` imports `silly_kicks.spadl` + `silly_kicks.id_compat` + numpy/pandas **only** — **never `silly_kicks.tracking`**. Enforced by an AST import-allowlist test (Task 1). Nothing imports `team_metrics`.
- **A `compute_*`, not an `add_*`.** No `add_*` aggregator, no `*_xfns`, in no default xfn list. The C4 action-coupled aggregator count stays **33**.
- **Canonical-id discipline (ADR-019).** All id grouping/compares go through `silly_kicks.id_compat` (`canonical_id_series` / `ids_equal` / `ids_match`); **raw** ids are emitted in output. Never a raw `==` on id columns.
- **Honest-NaN, never a fabricated zero (ADR-042/ADR-027).** A KPI whose inputs are absent emits NaN; a real `0` stays distinct from an undefined one. Every band is tested from **both** sides.
- **Reuse `spadl.add_possessions`** (never fork a possession definition). `TeamKpiParams` fields `possession_max_gap_seconds` / `possession_retain_on_set_pieces` map to the real kwargs `max_gap_seconds` / `retain_on_set_pieces`; the 3 precision opt-ins stay at defaults.
- **Orientation (ADR-028/ADR-045).** Opponent-relative KPIs (PPDA, field tilt) combine both teams' rows in one pitch frame via the `silly_kicks.reflection` seam; guarded by a **per-row** test (an aggregate mean is vacuous).
- **Geometry from `spadlconfig` (ADR-050)** — final third, penalty area, pitch dims. No hardcoded coordinates. Import as `from silly_kicks.spadl import config as spadlconfig`.
- **Use SPADL `type_id` / `result_id` (ints), NEVER `type_name` / `result_name`** (the latter are `add_names`-only; `territory` precedent). Resolve names via `spadlconfig.actiontype_id[name]` / `spadlconfig.result_id[name]`. All fixtures and implementations use the integer id columns. (Action type ids: pass=0, cross=1, throw_in=2, freekick_crossed=3, freekick_short=4, corner_crossed=5, corner_short=6, take_on=7, foul=8, tackle=9, interception=10, shot=11, shot_penalty=12, shot_freekick=13, clearance=18, bad_touch=19, dribble=21, goalkick=22; result success=1, fail=0.)
- **`TeamKpiParams.for_provider` ships EMPTY** (ADR-009) — every provider resolves to the base default; a per-provider tune is a separate gated PR, never this cycle.
- **No new runtime dependency.** `statsbombpy` is added scripts-only (undeclared today; used via `importorskip` in an e2e test).
- **Commit discipline (OWNER RULE — overrides any per-task/per-step commit cadence).** There are **NO per-task and NO per-step commits** in this plan. The entire module + driver + tests is **ONE coherent commit**, made **only** after every task is green, the full CI-faithful suite passes, and the **owner explicitly approves that specific commit** (Task 10). # silly_kicks/team_metrics/_config.py
from __future__ import annotations
import dataclasses
from dataclasses import dataclass, field
from silly_kicks.spadl import config as spadlconfig

@dataclass(frozen=True)
class CounterpressWindow:
    """A counter-press regain window: exactly ONE of seconds= or passes= (spec §4.1 XOR)."""
    seconds: float | None = None
    passes: int | None = None
    def __post_init__(self) -> None:
        if (self.seconds is None) == (self.passes is None):
            raise ValueError("CounterpressWindow requires exactly one of seconds= or passes=")

@dataclass(frozen=True)
class TeamKpiParams:
    """Frozen KPI params. NOTE: `counterpress_seconds` (v1 recoveries-within-Ns, a FIXED window) and
    `counterpress_window` (v2 configurable seconds-XOR-passes) are DISTINCT by design and both default
    to 5 s — the v1 Twelve-glossary metric and the v2 practitioner window are separate KPIs, not a dup.
    """
    possession_max_gap_seconds: float = 7.0            # -> add_possessions(max_gap_seconds=)
    possession_retain_on_set_pieces: bool = True       # -> add_possessions(retain_on_set_pieces=)
    defensive_action_types: tuple[str, ...] = ("tackle", "interception", "foul")
    ppda_zone_fraction: float = 0.6
    long_ball_distance_m: float = 32.0
    counterpress_seconds: float = 5.0                  # v1 recoveries-within-Ns window (fixed)
    counterpress_window: CounterpressWindow = CounterpressWindow(seconds=5.0)  # v2 configurable window
    post_recovery_window_seconds: float = 10.0
    retained_after_seconds: float = 5.0
    high_opportunity_xg: float = 0.15
    switch_min_lateral_m: float = 30.0
    # spec §5 geometry-derived fields (from spadlconfig at import time; immutable):
    channel_boundaries: tuple[float, float] = (spadlconfig.field_width / 3.0,
                                               2.0 * spadlconfig.field_width / 3.0)
    build_up_zone_max_x: float = spadlconfig.field_length / 3.0
    _is_universal_default: bool = field(default=False, compare=False, repr=False)

    @classmethod
    def default(cls, *, force_universal: bool = False) -> "TeamKpiParams":
        return cls(_is_universal_default=not force_universal)

    @classmethod
    def for_provider(cls, provider: str) -> "TeamKpiParams":
        return dataclasses.replace(cls(), **_PROVIDER_TEAM_KPI_PARAMS.get(provider, {}))

    def is_default(self) -> bool:
        return self._is_universal_default

#: EMPTY until an ADR-009 apply-gate clears (a per-provider tune is its own gated PR).
_PROVIDER_TEAM_KPI_PARAMS: dict[str, dict] = {}

#: Documented named counter-press windows (seconds XOR passes). Constant, not a mutable param.
#: Plug into TeamKpiParams(counterpress_window=COUNTERPRESS_PRESETS["tigres_hunt"]).
COUNTERPRESS_PRESETS: dict[str, CounterpressWindow] = {
    "barcelona": CounterpressWindow(seconds=6.0),
    "coventry": CounterpressWindow(seconds=5.0),
    "leipzig": CounterpressWindow(seconds=10.0),
    "hammarby": CounterpressWindow(seconds=5.0),
    "tigres_hunt": CounterpressWindow(passes=3),
}

## Task 2: Possession-foundation layer (`_possession.py`)

**Files:**
- Create: `silly_kicks/team_metrics/_possession.py`
- Test: `tests/team_metrics/test_possession.py`, add fixtures to `conftest.py`

**Interfaces:**
- Consumes: `spadl.add_possessions`, `spadl.spadlconfig`, `id_compat`.
- Produces: `add_possession_context`, `build_spells`, `possession_minutes` (signatures in the Interfaces summary).

**Definitions (pin these):**
- A **possession's duration** = `time_seconds(last action) − time_seconds(first action)` within the possession (period-relative; ADR-017). Single-action possessions → duration 0.0.
- **team_in_possession** for a possession = the team owning the majority of its non-NA `team_id` actions (ties → the first action's team). Emitted in the possession's raw id dtype.
- **is_open_play** = the possession's first action is not a set-piece restart (`freekick_short/_crossed`, `corner_short/_crossed`, `throw_in`, `goalkick`, `shot_freekick`, `shot_penalty`).
- **is_recovery** = `team_in_possession` differs (via `id_compat.ids_differ`) from the previous possession's team, within the same game+period.
- **in_possession_min** for team A = Σ durations of A-owned possessions / 60; **out_of_possession_min** = Σ durations of the opponent's possessions / 60.

**Interfaces:**

- Produces: `compute_pressing_kpis(actions_ctx, spells, minutes, *, params) -> pd.DataFrame` keyed `(game_id, team_id)` with columns: `ppda`, `defensive_intensity`, `time_to_defensive_action_s`, `time_to_recovery_s`, `recoveries`, `recoveries_within_ns_pct`, `counterpress_regains`, `counterpress_regain_pct`. Also `reflect_into_team_frame` in `_orientation.py`.

**KPI definitions (exact — implement each; NaN cases per spec §8):**

| Column | Formula | NaN when |
|---|---|---|
| `ppda` | opp passes in zone ÷ our defensive-action count in zone; zone = `x >= (1 - ppda_zone_fraction) * pitch_length` in the team's action-LTR common frame (opponent reflected in). Defensive actions = `params.defensive_action_types`. | 0 defensive actions in zone |
| `defensive_intensity` | count(defensive actions) ÷ `out_of_possession_min` | `out_of_possession_min == 0` |
| `time_to_defensive_action_s` | mean over losses of (first defensive action time − loss time); loss = end of an own possession | no loss with a subsequent defensive action |
| `time_to_recovery_s` | mean over losses of (regain time − loss time); a loss never regained is excluded from the mean | no loss ever regained |
| `recoveries` | count of `is_recovery` possessions for the team | (always defined; 0 is real) |
| `recoveries_within_ns_pct` | fraction of recoveries whose gap (loss→regain) ≤ `counterpress_seconds` | `recoveries == 0` |
| `counterpress_regains`, `counterpress_regain_pct` | per loss, regain within `params.counterpress_window` (`CounterpressWindow`, seconds XOR passes): **seconds** arm → `(regain_time − loss_time) ≤ seconds`; **passes** arm → the opponent completes `≤ passes` passes between loss and regain (Tigres "Hunt"). Count of within-window regains + pct over losses. The seconds/passes dispatch reads `window.seconds is not None`. | no losses |

# tests/team_metrics/test_orientation.py
import numpy as np, pandas as pd
from silly_kicks.team_metrics._orientation import reflect_into_team_frame
from silly_kicks.spadl import spadlconfig

def test_reflect_is_point_reflection_per_row():
    opp = pd.DataFrame({"start_x":[10.0, 90.0], "start_y":[5.0, 60.0],
                        "end_x":[20.0, 80.0], "end_y":[10.0, 50.0], "team_id":[20,20]})
    out = reflect_into_team_frame(opp)
    fl, fw = spadlconfig.field_length, spadlconfig.field_width
