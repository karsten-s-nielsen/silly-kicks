# VAEP, atomic-SPADL, causal & calibration

> On-demand class-2 context (ADR-102-style store). The current terse RULES live in `AGENTS.md`; this file holds the WHY / history / measurement. See the spec `docs/superpowers/specs/2026-09-24-agents-md-restructure-design.md`.

- **VAEP** (`vaep/`): Feature engineering + gradient boosting binary classifiers. `HybridVAEP` removes result leakage from a0 features. xG-targeted labels available via `xg_column` parameter. PR-S32 ships TF-29 design-space variants: `window` parameter on `scores()`/`concedes()` (`"action"` / `"possession"` / `"time"`); `xfns_default_no_goalscore` / `hybrid_xfns_default_no_goalscore` goalscore-bias-control lists. **4.13.0 (ADR-018): own goals are counted by RESULT (`result_id==owngoal`), not via a `type_name` shot-gate** — single-source `_is_goal`/`_is_owngoal` helpers in `vaep/labels.py` (all sites route through them; a guard test forbids the old shot-gated owngoal predicate). Fixes a codebase-wide undercount (every converter emits own goals as `bad_touch`, which the old `str.contains("shot")` gate zeroed out); the atomic label path already counted them. Hyrum: shifts scores/concedes/xG label distributions for all providers (VAEP-model retrain trigger).

- **Causal** (`causal/`): Public since 4.47.0, promoted out of `_causal/` (ADR-015) -- pure numpy/sklearn, no R, no new runtime dependency. `matching.py` (propensity-score matching; ATT/ATNT; 1:1 nearest-neighbour **with replacement**, no caliper; logistic PS on standardized covariates; Abadie-Imbens 2006 matching SEs; cluster-aware `placebo_shift` with whole-cluster reassignment), `opportunities.py` (spell state-machine opportunity rows behind an `OpportunityConfig` builder surface), `power.py` (`att_power_curve`, `icc_power_curve`) and `_confounders.py`. The known-truth method tests in `tests/causal/` gate CI; applied results are REPORTED, never gated.

- **Atomic-SPADL** (`atomic/`): Variant where actions are decomposed into atomic sub-actions (receival, interception, out, etc.).

- **Calibration** (`calibration/`): TF-24 Optuna calibration harness (optional `[calibration]` extra; lazy-import-guarded, NOT imported by `silly_kicks/__init__`). Pure provider-agnostic objectives/CV/gates: `CarrierAccuracyObjective` (Stage 1 carrier accuracy, maximize) + `AugmentedVaepBrierObjective` (Stage 2 augmented-VAEP held-out Brier, minimize) — a `ruthless` `CachedObjective` with invariant-prepare + per-trial-patch and a deterministic-XGBoost cache-equivalence guarantee (`assert_cache_equivalence`, 1e-9); match-stratified CV (`GroupKFold(5)` for >7 matches / leave-one-match-out ≤7); `FrozenXt` frozen **exogenous** xT artifact (fit once on a corpus disjoint from the calibration matches, sha256 + fail-closed exclusion, train–serve-consistent); H1 stateless default-Brier-anchored penalty + per-provider signal-sanity + DAS-degradation surfacing + TF-25 provider-specific-defaults gate. I/O lives in `scripts/calibrate_tracking_defaults.py` (CLI) + `scripts/_loader_pining.py` (SkillCorner/IDSSE public, Gradient Sports owner-tier) + `scripts/_loader_databricks.py` (bronze). The harness **recommends** values + an auditable manifest; it does NOT change the library default constants (separate "apply" PR). Decision: ADR-009. **SK-xT-3 (4.20.0)** adds `XtBandwidthObjective` + `xt_bandwidth_config` + `scripts/calibrate_xt_bandwidth.py` — a per-corpus `bandwidth × GridSpec-resolution × adaptive` sweep minimizing K-fold held-out xT **transition-NLL** (Singh baseline reported alongside; recommendation scoped to destination-likelihood with a reported Spearman-vs-goals cross-check, ADR-009 amendment + ADR-021). Plain duck-typed objective (resolution-keyed lazy cache, NOT a `CachedObjective`); caches the small per-`(grid,fold)` grouped destinations and shares the vectorized gaussian `_gaussian_transition_from_grouped` seam with `xthreat` (gaussian KDE re-pinned to the vectorized core — Chesterton-verified single caller; sklearn retained for non-gaussian kernels). Does not change library defaults. **Item C (ADR-060, 4.81.0)** makes the Stage-1 recommendation honest about non-identifiability: it is a **prefer-incumbent** selection over the indistinguishable `beta`/`gamma` set — move only if a candidate clears BOTH an effect-size floor (`MIN_EFFECT_SIZE`) AND a paired-difference-SE test (the shared `exceeds_noise_floor`, which also backs `tf25_gate_fires`) — plus a standing fold-stability diagnostic. **`tolerance_m` is a held constant with zero swept/recommended/consumed representation:** removed from `stage1_config` + `CarrierAccuracyObjective`, absent from the provenance-stamped `carrier_selected.json`, and sourced by Stage 2 from `DEFAULT_CARRIER_PARAMS`; Stage 2 REFUSES an unprovenanced or dirty selection artifact. New public surface: `select_recommended_point`, `PointScore`, `Selection`, `build_selection_artifact`, `exceeds_noise_floor`, `MIN_EFFECT_SIZE`. Additive — no library default changes (ADR-009 preserved). Decision: ADR-060.
