# Tracking-consuming counterfactual metrics

> On-demand class-2 context (ADR-102-style store). The current terse RULES live in `AGENTS.md`; this file holds the WHY / history / measurement. See the spec `docs/superpowers/specs/2026-09-24-agents-md-restructure-design.md`.

- **Territorial defense — SB360 removal counterfactual (`territorial_defense/`):** TF-54b (ADR-090). The tracking-consuming counterfactual counterpart of `territory`: per-`(defender, match)` valuation of how much a defender's *positioning* suppresses the attacking team's threat on StatsBomb-360 freeze-frames, via a **model-free removal (marginal-contribution) counterfactual**. `compute_territorial_defense(actions, frames, *, xt, params)` → `(samples, TerritorialDefenseReport)`. **Mechanism:** `a_threat_suppressed = compute_threat_pc(counterfactual) − compute_threat_pc(actual)`, where the counterfactual is the factual frame with **one defender row REMOVED** (pitch control re-partitions the vacated space to the remaining players — Fernández–Bornn marginal player value); replacement (ghost) DEFERRED. **Sign convention: attacker-value units, `positive = threat suppressed`** (INVERTED from gkdv's "negative = deterrent"; the probe direction registry encodes `positive`). **Two arms:** **Arm A** (`a_threat_suppressed`) is action-anchored + **identity-EXACT** via the actor bridge, over the acting defender's own defensive actions (tackle/interception/clearance, `type_id ∈ {9,10,18}`); **Arm B** (`b_threat_suppressed`) is hull-based + attribution-**approximate** (nearest-to-target defender removed; single-sources the v1 `territory` trimmed hull via the newly-exported `build_trimmed_hull`/`Hull` with a configurable `own_half_max_x` matching `territory`), reporting `b_attribution_slippage` (the rate the position-chosen contesting defender is **NOT** the hull-owner D — attribution ERROR, **lower = tighter**, honest-NaN when identity is un-measurable on anonymous SB360 frames, NEVER a fabricated 0 per ADR-027). **Actor bridge:** SB360 freeze-frames are anonymous (`snapshot_to_tracking_frames` numbers the rows), so `is_actor` is re-plumbed through the StatsBomb port + `snapshot_to_tracking_frames` as a **snapshot-only** extension column (base `TRACKING_FRAMES_COLUMNS` unchanged) and `silly_kicks.keeper_identity.apply_actor_identities_to_frames` stamps the acting player's real id onto the anonymous actor row (shared home; ADR-078 bridge pattern, ADR-084 module home; independently useful — the eyestone GK build-up-decision metric is a concrete second consumer). Hexagonal — imports `silly_kicks.tracking` PUBLIC seams only; **nothing imports `territorial_defense`** and `tracking` never imports it (AST allowlist `tests/territorial_defense/test_import_allowlist.py`, whole-tree sweep incl. relative imports). A `compute_*`, NOT an `add_*` (C4 count stays 33); in NO default xfn list. **`pitch_control_method="spearman"` is a HARD `__post_init__` constraint** (a GK-blind method is unrepresentable, mirroring `GkdvParams`); the arms accept **no `pitch_control_cache` — that is CORRECTNESS not performance** (ADR-043 landmine: `PitchControlCache` keys on frame IDENTITY excluding player positions, so a removed-defender counterfactual carrying its twin's identity would be served the factual surface and every delta would collapse to exactly 0 with no warning). **Conservation + honest-NaN (ADR-042/ADR-027/ADR-055/ADR-063/ADR-077):** a removal on a defender-depleted frame (`< min_defenders_after_removal`, default 1) is dropped-and-counted `removal_undersupported` (a 0-defender surface degrades to attacker-controls-all — an upward-biased outlier, NOT a fabricated 0); an unresolvable goal end → `unresolved_geometry` honest-NaN (`GoalEndUnresolvedError` caught at the arm edge, ADR-055). **Goal resolution is per-frame from the action-LTR CONVENTION, dual-mode via `frame_convention` (ADR-091):** SB360 freeze-frames are per-acting-team-LTR (ADR-028), so a per-MATCH `resolve_defended_goals` (mean GK x) is bimodal and scores ~0 — the DEFAULT `frame_convention="per_action_ltr"` builds a per-frame `action_ltr_goal_map` (the acting team attacks x=105; GK-INDEPENDENT/FOV-proof, so keeperless frames still score), while `frame_convention="match_ltr"` reuses the per-match `resolve_defended_goals` for continuous-tracking-derived (home-attacks-right) frames. The compute OWNS the convention via a `goal_map_for` factory; `classify_arm_a_domain`/arms are convention-agnostic. **A convention-faithful `make_per_action_ltr_fixture` + a two-sided regression are load-bearing: the match-oriented e2e/audit fixtures masked a metric that scored 0 on real SB360.** An under-observed local region → `fov_cropped_local` (SPEC-02 local-completeness gate); the removal-depletion guard applies to BOTH arms, and `TerritorialDefenseReport` conserves BOTH — Arm A over its domain (`n_frames_scored + Σ drops == n_frames_in`) and Arm B over its qualifying `(defender, in-hull-pass)` pairs (`arm_b_n_scored + Σ arm_b_drop_reasons == arm_b_n_in`). Threat suppression is a Tier-1 dimensionless LIFT at zero velocity (ADR-063). ids canonical via `id_compat` (ADR-019). `TerritorialDefenseParams` frozen (`for_provider` empty per ADR-009). **DEMOTED to experimental (4.112.0 commit 2, ADR-090 construct-validity below):** the public metric surface is REMOVED — out of `territorial_defense.__all__` (now empty), out of `feature_glossary` (glossary count reverts −3 → 394), and out of the SB360 boundary audit (`BOUNDARY_ENTRY_POINTS`, `NOT_EXERCISED_BUDGET` 50→46); the metric + arms + engine are retained as PRIVATE modules (`._compute`/`._arms`/`._engine`, imported by the `scripts`/tests consumers from the private path) for the replacement-ghost redesign, mirroring the TF-60 Layer-3 arms (ADR-089). The `territorial_defense` C4 container stays (the code exists; no analyst-facing edge) and `NOTICE` keeps the attribution for the retained code. **HONEST LIMIT (load-bearing): the metric is NOT construct-validated (battery verdict below), and per-defender numbers are NOT player-attributable** — the marginal-removal delta is **team-conditioned by construction** (vacated space re-partitions to teammates); in a single-tournament / national-team corpus (WC2022 + 30 licensed SB360) the defender-vs-team confound is **unidentifiable** (one player = one national team → zero cross-team defender observations), so **per-defender numbers are NOT a defender ranking** and the elite-defender ("Van Dijk") prior is elite-defender/elite-team **collinear** (FACE-VALIDITY, not attribution). Ranking is a future ADR-009 gated on a crossed defender+team **ICC** over a **multi-club transfer** corpus. The owner-run construct-validity battery (`scripts/validate_territorial_defense.py`; ADR-052 shards, ADR-037 clean-tree, ADR-056 input contract, locked pre-registered prior) **RAN on 321 SB360 matches (`docs/research/territorial_defense_construct_validity/`) and returned a NEGATIVE verdict — Layer-0 `instrument_void` + Layer-1 `not_responsive` (pooled dose median 0.0 vs single-player placebo p95 0.137; named-defender face-validity 2/3 at noise-level magnitudes)** — so per the standing rule (*a metric that fails validation must not ship as that metric*) the public metric surface is REMOVED (demotion above); **reported-not-gated** (promotes NO default). Additive — no VAEP/tracking retrain, no re-materialize. Decision: ADR-090 (per-action goal resolution + `frame_convention` amended by ADR-091).

- **Positioning — prescriptive defensive-positioning optimiser + measured positioning gap (`positioning/`):** TF-56 (ADR-104), from databallpy `optimization` (Oonk & Shah, MIT). The **PRESCRIPTIVE sibling of GKDV's descriptive counterfactual**: a pure simulated-annealing solver `optimise_positions(frame, *, movable, objective, constraints, optimizer=None, seed=None) -> OptimizeResult` searches for the best REACHABLE defensive shape under a composable objective + per-player TTI reachability, plus a measured `compute_positioning_gap(frames, *, xt, movable=None, objective=None, params) -> (samples, PositioningReport)` at **frame/team grain**: `positioning_gap = threat(actual) − threat(reachable optimum) ≥ 0` per defensive frame. **Objective-agnostic solver behind `Objective`/`Constraint`/`Optimizer` protocols (no God-object); the shipped glossaried column freezes to ONE canonical `ThreatObjective`** (`compute_threat_pc`, spearman, GK-aware `lambda_gk`, `goal_map`-oriented) — `WeightedSum`/`CappedContribution`/`PressureObjective`/`DasObjective` are EXPLORATORY (a weighting IS a tactical choice; consumer-side per the raw-primitives convention, ADR-009). **`gap ≥ 0` by PATH IDENTITY, not two independent calls:** `OptimizeResult.actual_score` is the SA incumbent-0 evaluation (the SAME code path as `best_score`), and the metric takes `threat_actual = opt.actual_score`. **DETERMINISTIC:** the RNG is seeded from `(game_id, period_id, frame_id)` via `hashlib` (process-independent, never Python's salted `hash`), so the column is a pure, CI-golden-able function of inputs. **`ThreatObjective` computes the surface DIRECTLY, NEVER `PitchControlCache`** (ADR-043 identity-key landmine — a moved-defender frame would be served the factual surface and every gap would collapse to 0; non-vacuity-gated). **`ReachabilityConstraint`** = `compute_tti(REAL pos+vel, candidate) ≤ max_reach_seconds`, evaluated against the player's REAL state (never a mid-search intermediate); frozen `ReachabilityParams(max_reach_seconds=0.7, reaction_time=0.1, max_acceleration=7.0=SpearmanParams)`; an infeasible candidate is rejected at the SA proposal, never scored. **Movable default = the defending team's OUTFIELDERS; the GK is EXCLUDED from `movable`** (keeper positioning is GKDV's domain) but stays a FIXED agent contributing via `lambda_gk`. **`pressure_on_target(frame, player_id, *, method, params) -> float` (NEW public `tracking` primitive) REUSES `pressure_on_actor` via a synthesized one-row action — `add_pressure_on_actor` is UNTOUCHED** (no delegation refactor, no new golden; the existing `tests/tracking/test_pressure_*.py` remain the guard). **Domain (per-condition census, spec §6):** alive ball ∧ opponent-in-possession ∧ ball within `domain_ball_to_goal_m` (35.0 = gkdv's `_DOMAIN_BALL_TO_GOAL_M`) of the DEFENDED goal ∧ two-team frame ∧ velocity present ∧ ≥1 movable; 1 fps downsample; each drop attributed to its own `positioning_gap_source` token (`excluded_not_two_teams` is DISTINCT, not folded into `excluded_out_of_domain`); `PositioningReport` conserves (ADR-042); honest-NaN, never a fabricated 0. **Velocity Tier-3 (ADR-063):** a declared-velocity-less frame → `velocity_unavailable` excluded-and-counted; undeclared-missing `vx`/`vy` → RAISE (fail-loud). **SB360 is OUT of v1** — the blocker is FOV partial-observation of the shape + from-rest reachability (NOT "no DAS"; the threat objective is Tier-1 at zero velocity). Oriented via `resolve_defended_goals` (ADR-055), never team identity. **Hexagonal:** imports `silly_kicks.tracking` PUBLIC seams + `id_compat`/`reflection`/`spadl.config` ONLY, never a `tracking._*` private, never `silly_kicks.xthreat` (`xt` INJECTED, the port pattern); **nothing imports `positioning`** (AST allowlist both directions). A `compute_*`, NOT an `add_*` → the action-coupled aggregator count STAYS 33; in no default xfn list; **no `*_xfns`** (frame-grain, reads no gamestate/outcome); +1 C4 container. Frozen params (ADR-009, `for_provider` empty). Canonical-id grouped (ADR-019). `metric_contracts` registers `POSITIONING_METRIC_COLUMNS` + grain `("game_id", "team_id")` (ADR-098). Glossary +3 (`positioning_gap`/`threat_actual`/`threat_optimum`, `higher_is_better=False`). NOTICE: Oonk & Shah / Le et al. 2017 / Spearman / Bekkers / Pleuler TTI. **PERF (MEASURED, not estimated): ~1.8 s/scored-frame @ 2000 SA iters** (`ThreatObjective` recomputes a full pitch-control surface per iteration — the cache is refused by design), so the bounded velocity-bearing corpus is feasible and the coarse-grid-search lever is NOT v1 (registered, reserved). Structural guards: `compute_threat_pc` runs exactly `1 + n_feasible_proposals` per solve (no quadratic re-score); one feasibility check per iteration (linear in the budget — the `compute_threat_pc` count is NOT the linearity proxy, being confounded by the cooling feasibility ramp). **HONEST LIMIT (load-bearing):** `positioning_gap` scores the REACHABLE improvement, so a dose that displaces a defender AWAY from its reachable-improvement zone SHRINKS the recoverable gap — the naive "worse position → larger gap" is empirically FALSE (the dosed position carries its own shifted reachable set) AND the gap is orthogonal to concurrent shape-badness (corr(threat_actual, gap) = −0.20), so the dose instrument is RETIRED (spec §8 amendment, owner-ratified 2026-09-22). Instrument validity = optimizer-STABILITY (seed/iteration-invariant optimum; requires the spike-fixed `init_sigma_m=2.0` — the retired 5.0 left the optimum seed-noisy, per-frame gap std 0.324 vs 0.000) + discrimination; the commit-2 ship gate is PREDICTIVE — a higher gap at t predicts more conceded threat over t+Δ (meaningful precisely because the gap is orthogonal to concurrent threat). **Status: NOT construct-validated** — the glossaried column ships ONLY if the owner-run commit-2 battery (`docs/research/tf56_positioning/`, `scripts/build_tf56_positioning_validity.py`) returns GO (predictive-positive-and-significant ∧ discriminating ∧ optimizer-stable/non-degenerate); a NEGATIVE battery DEMOTES it in the same release (out of `__all__`/glossary, code retained private — the territorial_defense / TF-60-arms precedent). Per-defender attribution/ranking DEFERRED (a future ADR-009 gated on a crossed defender+team ICC over a multi-club transfer corpus). Additive — no VAEP/tracking retrain, no re-materialize. Decision: ADR-104.
