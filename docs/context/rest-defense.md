# Rest-defense, ghost-GK grids & ghost-outfield

> On-demand class-2 context (ADR-102-style store). The current terse RULES live in `AGENTS.md`; this file holds the WHY / history / measurement. See the spec `docs/superpowers/specs/2026-09-24-agents-md-restructure-design.md`.

- **Restdefense — rest-defense structure + danger (`restdefense/`):** TF-60 (ADR-080 PR1, ADR-081 PR2). Descriptive rest-defense KPIs + danger-behind-line valuation for an IN-POSSESSION team (the rearguard it keeps while attacking, to blunt the counter after a loss), sampled at its on-ball **action grid** — the one grain shared by continuous tracking and StatsBomb-360 freeze-frames. Hexagonal — consumes `silly_kicks.tracking` PUBLIC seams only (and `gkdv` public delta seams in later cycles); **nothing imports `restdefense`** and `tracking` never imports it (pinned by `tests/restdefense/test_import_allowlist.py`). Oriented entirely via `resolve_defended_goals`/`GoalMap` (ADR-055; **never team identity**); honest-NaN on unresolvable geometry / non-two-team frames (never a fabricated 0; ADR-027), with a 3-valued `rd_geometry_source` provenance (`resolved`/`guessed`/`unresolved`). ids via `id_compat` (ADR-019), nullable dtypes (counts `Int64` / metrics `float64`). **Additive — no existing feature changes, no VAEP retrain, in NO default xfn list.**
  - **Layer 1 (PR1, ADR-080):** `compute_rest_defense`/`summarize_rest_defense` → 11 descriptive KPIs (numerical superiority incl. a GK-inclusive variant, zone occupancy, line/GK height, rearguard compactness/width [BACK-LINE, `compute_defensive_line`] + whole-team depth [`compute_team_shape.team_length` — the owner-ratified "Option B"], 2-3/3-2 stagger) + the first public goal-side counting primitive `count_goalside` (`group_rows`-batched + scale-guarded, ADR-068/073). Opt-in ADR-077 FOV companions on the count/region columns (ROI is a FIXED action-LTR zone, NEVER a `goal_map`). +1 C4 container.
  - **Layer 2 (PR2, ADR-081):** 5 additive Tier-1 danger columns on the samples table — `rd_attacker_space_control`, `rd_danger_behind_line`(+`_gk`), `rd_gk_coverage_behind_line`, `rd_gk_reachable_coverage_m2` — folding the in-possession keeper in as a `lambda_gk` control agent (**GK-blind base = A's keeper ROW dropped; GK deterrent contribution = base − gk, derivable, NOT a 6th column**; `lambda_gk=3.0` from `SpearmanParams`, one source, never duplicated in `RestDefenseParams`). Reuses TF-7 `compute_threat_pc`/`control_in_region` + TF-15 `compute_gk_influence`. **The WHOLE Layer-2 family is gated on a fitted `xt` (P2-02):** with no `xt`, all 5 are NaN BEFORE any pitch-control call, so Layer-1-only callers are byte-identical to PR1 (no pitch-control cost, no velocity precondition); an unfitted `xt` RAISES (fail-closed, 4.62.0). `rd_gk_reachable_coverage_m2` is Tier-2 → **honest-NaN on velocity-less providers** (ADR-063); the other four are Tier-1 lifts (zero-velocity positional model on SB360). Opt-in OBPV `w_field` re-weighting (`danger_field_weight`, OFF by default, un-tuned per ADR-009; `WFieldParams`). **Additive tracking seams, all default-`None`/re-export BYTE-IDENTICAL (no retrain):** `compute_threat_pc(field_weight=)` (per-cell weight hook, multiplied into the ORIENTED threat grid before the Voronoi partition), `compute_gk_influence(region=)` (region-restricted reachable area, velocity-suppression applied first), plus `zero_velocity_if_unavailable` and `compute_gk_influence` newly EXPORTED from `tracking`. SB360 boundary-audit verdicts: the 4 pitch-control metrics `differs_by_design` (Tier-1 lift), reachable m² `honest_nan`, entry `verdict_provenance="substantive"`. C4 unchanged. **PR3 (GK-ghost `sweeper` re-fit, ADR-083) SHIPPED** — the §9 in-possession-validity gate FIRED (the shipped ghost saturates at its 30 m label ceiling). **PR5 (the trained ghost-outfield model `tracking/_ghost_outfield.py`, ADR-087) SHIPPED** (arc reordered: PR5 before PR4).
  - **Layer 3 (ADR-089; arms DEMOTED to experimental 2026-09-08):** The shipped, durable part is the **ghost-GK goal-relative convention, unified to the correct both-axes 180° point reflection** (retrain all 5 variants) + **both ghost serves return frame-ready `ghost_x`/`ghost_y`** so no consumer re-derives orientation (gkdv `_engine` consumes them; the old x-only engine conversion mislocated the away-team keeper in y). **gkdv arm values change for away-team keepers → gkdv re-materialize + TF-19 sign-off re-run in-cycle.** The counterfactual **engine** `restdefense/_counterfactual.py::build_restdefense_ghost_frames(which="keeper"|"rearguard", ...)` is a gkdv SIBLING (not a gkdv call; PURE; drop-and-counted `RestDefenseGhostReport`; a non-finite served ghost RAISES) and stays PUBLIC as metric-free infrastructure. **The deterrent ARMS (`restdefense/_arms.py`: `rest_defense_{outfield,gk}_deterrent`, `merge_rest_defense`) are DEMOTED to experimental** — an out-of-sample validity study (`docs/research/tf60_layer3_construct_validity/`) found the outfield arms **confounded with attacking commitment** (matched-ATT signal collapses under a commitment control; ≈76% mediated by turnover position; only the keeper-threat arm is control-robust, and only pooled/on SkillCorner), so they are **NOT** in `restdefense.__all__`, **NOT** glossaried, **NOT** SB360-boundary-registered; the code is retained privately for the redesign. Durable contracts still binding the experimental code: **`B = the OPPONENT` via `ids_differ`** (column-vs-column, NEVER `ids_match` Series-vs-SCALAR → all-False → B silently = A); the keeper counterfactual attaches A's keeper `player_id` to the served `(frame, team)` row (else `no_ghost_served`); the keeper arm uses the **sweeper** ghost-GK, never the frozen default; `restdefense/_probe.py` REUSES gkdv's PUBLIC `layer0_instrument_verdict`/`layer1_responsiveness_verdict`. **`compute_rest_defense` returns an empty declared-columns table on a zero-committed-sample match** (Layer-1/2, shipped). The **redesign** — a within-turnover counterfactual counter that removes the commitment confound (price B's realized counter under actual-vs-ghost rearguard holding the turnover event FIXED) — is registered (`docs/superpowers/specs/2026-09-08-tf60-counterfactual-counter-redesign-design.md`). Additive to VAEP, C4-free (derived-feature-column count reverts 398→394). Decision: ADR-089.

- **The ghost-GK grid is a first-class per-model `GhostGridSpec`; `sweeper` is an ADDITIVE extended-grid variant (ADR-083, TF-60 PR3).** `GhostGridSpec` (frozen `x_min/x_max/y_min/y_max/resolution` + derived `nx`/`ny` + a 7-key `to_metadata_dict()`) replaces the module-global `GRID_*` constants and is threaded through `__init__`/`save`/`load`/the label-domain filter/`serve_ghost_gk_positions`'s `ghost_out_of_box` (a pre-refactor artifact with no `grid_spec` key loads `DEFAULT_GHOST_GRID`). `default`/`position_only`/`full` stay on `DEFAULT_GHOST_GRID` (`x_max=30`) and are **BYTE-IDENTICAL** — proven THREE ways because a full metadata-SHA round-trip is UNACHIEVABLE (`save()` recomputes `feature_contract.probe_sha256`): unchanged golden/chirality/feature-contract/KDE tests + `DEFAULT_GHOST_GRID.to_metadata_dict()` equals `default`'s committed `grid_spec` + a re-save of `default` differs ONLY in `feature_contract`. The additive `sweeper` (faithful, 26 feats) / `sweeper_position_only` (velocity-less, 21 feats) pair (`x_max=52.5`) exists because the shipped ghost hard-SATURATES at its 30 m label ceiling and cannot place an in-possession high sweeper (`ghost_out_of_box` is BLIND — the clip is on the OUTPUT, out-of-domain is an INPUT property). The `_resolve_ghost_model_for_frames` `model=="sweeper"` branch is placed BEFORE the `model is not None` custom short-circuit and velocity-keys WITHIN the family, so **gkdv (`None`/`"default"`/instance) NEVER selects it → NO GKDV retrain, NO VAEP retrain**; a missing `sweeper_position_only` → honest NaN, never the invalid-on-velocity-less default (ADR-067 asymmetry). **`predict_density` is DEFAULT-GRID-ONLY (fail-loud on a non-default grid)**; the mean/serve path (`predict_mean`/`compute_ghost_gk`/`serve_ghost_gk_positions`) is grid-independent and works on the extended grid. `train_ghost_gk.py` gains `--grid-x-max` (keyed into the shard-generation token — the 4.77.1 stale-shard rule) + `--variant sweeper|sweeper_position_only`. Bundled from the same 179-match public corpus, CLEAN `training_commit`; parity 1.2e-13 (exact); **the >30 m high-sweeper training signal is IDSSE/Sportec-dominated (11.5 % coverage), Gradient Sports 0.0 %** (a reported corpus characteristic, §6/§7.3 report-not-gate). PR4's GK arms MUST consume `from_variant("sweeper")`, never the frozen default. Additive — no retrain, no re-materialize, C4-free. Decision: ADR-083.

- **The ghost-OUTFIELD rearguard model is a boosted-MEAN point estimate, possession-CONDITIONED, and a SERVE SEAM — not an aggregator (ADR-087, TF-60 PR5).** `tracking/_ghost_outfield.py::GhostOutfieldModel` is the outfield sibling of the frozen ghost-GK model: gradient-boosted MEAN x/y ensembles (HGBR, reusing the ADR-076 numba leaf-walk) predicting a league-average rest-defense rearguard position per `(frame, team, lateral slot)` — **NOT** RFCDE/KDE density (PR6's arm differences a POSITION, so it needs a point estimate, not a distribution). Served by `serve_ghost_outfield_positions` (goal-relative `ghost_gr_x`/`_gr_y` + the actual `player_id` bookkeeping key + `ghost_outfield_source`) — a **serve seam, NOT an `add_*`**, so the C4 aggregator count stays 33 and it is in NO default xfn list. **The 20/16-feature vector is LEAKAGE-SAFE by construction: no feature encodes the modeled team's OWN rearguard coordinates** (the prediction target) — it is ball state + opponent counter-threat geometry + context + the lateral `slot_index` rank; guarded by an output-invariance test (perturb the target → features byte-identical). **Possession-CONDITIONED — ONE model serves BOTH regimes (the ADR-055 discriminator idiom):** training (`both_teams=True`) extracts BOTH non-ball teams' deepest-`n` per frame with a live `team_in_possession` feature (1 = the ball-carrier's rest-defense rearguard, 0 = the defending line); serving defaults to the in-possession slice (`both_teams=False`), and the serve/PR6 API is unchanged. Standard ghost-artifact conventions REUSED verbatim: pickle-free `model.npz`+`metadata.json`+`SHA256SUMS`, fail-closed `load()` (SHA-256 + chirality + feature-contract, ADR-011/040/050). **The chirality frame hash is pandas-major-INVARIANT** (`_canonical_frame_sha` coerces the probe frame to native scalars before `json.dumps` — `to_dict("records")` yields numpy scalars on pandas 3 that `default=str` serializes as JSON strings vs native JSON numbers on pandas 2, a different digest per major, ADR-057; the stored native digest is reproduced on BOTH majors so it is backward-compatible with no metadata regen, verified byte-identical, and a bundled-weights load+finite-predict CI gate runs on every leg). **The serve resolver RAISES on a PRESENT-but-unloadable artifact** (a bad SHA / chirality skew is corruption, never a silent all-NaN `variant_unavailable` column); an ABSENT variant stays honest-NaN. **Velocity-keyed `default`/`position_only` auto-select (ADR-067)** — a velocity-less freeze-frame with no bundled `position_only` → honest-NaN, NEVER the invalid default — and **FOV cropped-honest-NaN serving (ADR-077)**: a served frame whose rearguard region is under-observed is `ghost_outfield_source="fov_cropped"` NaN, never a fabricated ghost from the deepest-`n` VISIBLE players (`GHOST_OUTFIELD_SOURCE_VALUES = {"computed", "variant_unavailable", "fov_cropped"}`). **Trained at 1 fps** (mirroring the ghost-GK trainer; 25 fps is massively autocorrelated → ~25× fewer rows, no meaningful loss for a mean model; folded into the shard-generation token per the 4.77.1 rule), from the **179-match public corpus**, CLEAN `training_commit`; CV euclidean MAE 6.00 m (`default`) / 6.07 m (`position_only`), coherence `ordering_fraction=1.0`. `train_ghost_outfield.py` resolves the tc3 cache's flat `_actions/{game}.parquet` and reads the `meta.json` home for the `score_diff` perspective, and subsamples via `--subsample-fps` (default 1.0). Additive — no VAEP/tracking retrain, no re-materialize, C4-free. Decision: ADR-087.
